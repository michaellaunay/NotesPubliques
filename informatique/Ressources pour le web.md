# Ressources pour le web

> [!abstract] Objectif
> Trouver vite, pour un site, une maquette ou un support de cours, des ressources graphiques utilisables sans contentieux : logos de substitution, illustrations, icônes, polices, palettes, outils de retouche et de mise en scène — en sachant lire leur licence.

> [!info] État de la fiche
> Réorganisée le 29 août 2026. La liste de 2023 provenait d'un billet LinkedIn de Yoann Lopez et contenait trois liens raccourcis `lnkd.in` : deux ont été identifiés à partir de leur description (City Roads, Old Book Illustrations), le troisième reste signalé. Logodust et LogoToUse existent toujours (vérifié) ; les autres sites n'ont pas pu être contrôlés depuis le bac à sable — un lien mort se remplace, la fiche ne le devine pas.

Voir aussi : [[HTML]], [[CSS]], [[Outils IA]] (génération d'images), [[Droits d'auteur]].

# 1. Lire la licence avant de télécharger

- **Domaine public / CC0** : usage libre, même commercial, sans attribution (Old Book Illustrations pour les gravures anciennes, Openverse pour chercher).
- **Licences libres avec attribution** (CC BY, MIT, Apache) : citer l'auteur ; c'est le cas de la plupart des jeux d'icônes.
- **« Gratuit »** n'est pas « libre » : beaucoup de sites autorisent l'usage mais interdisent la redistribution ou exigent un lien ; les logos de substitution sont faits pour des maquettes, pas pour une marque réelle.
- Les images générées par IA posent leurs propres questions (voir [[Outils IA]], chapitre 9).
