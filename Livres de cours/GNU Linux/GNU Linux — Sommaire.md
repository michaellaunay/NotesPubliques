# GNU Linux — Sommaire


Ce livre suit la progression d'un administrateur qui découvre le système : d'où il vient et comment il est distribué ; comment l'installer et s'en servir ; ce qu'il y a dedans — démarrage, processus, isolation, disques, journaux ; ce qu'on lui fait servir — réseau, web, messagerie, annuaire, conteneurs ; et comment on le protège.
